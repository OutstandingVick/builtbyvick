# Built by Vick

Built by Vick is the personal portfolio of Victor Poweidei Ogbonna, a frontend and product engineer who builds responsive digital products, developer-facing tools, and research-informed experiences.

The website presents Victor's background, technical skills, professional experience, selected projects, remote collaboration testimonials, and contact information in a responsive single-page experience. It includes light and dark themes and is designed to work across mobile, tablet, and desktop displays.

## Live Website

[builtbyvick.work](https://builtbyvick.work)

## Features

- Responsive portfolio layout
- Light and dark mode
- About and technical skills sections
- Interactive work-experience carousel
- Featured engineering and Web3 projects
- Remote collaboration testimonials
- Contact form and social links

## Built With

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://motion.dev/)
- [Lucide](https://lucide.dev/) and [React Icons](https://react-icons.github.io/react-icons/)

## Local Development

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

```bash
npm run dev    # Start the development server
npm run lint   # Run ESLint
npm run build  # Create a production build
npm run start  # Start the production server
```

## Deployment

The website is deployed with [Vercel](https://vercel.com/) and connected to the custom domain `builtbyvick.work`.
